# 登录自动用户ID

提出：微信登录后自动生成稳定唯一的用户ID；保留昵称和头像的微信选择或自行上传能力。

确认：用户要求直接执行。用户ID不能使用或暴露OpenID，也不允许客户端自行修改。

实现：
- 服务端根据账号内部标识生成固定格式的公开用户ID，并在登录时创建或补齐资料。
- 旧账号无需清空资料，下一次登录或刷新自动获得相同用户ID。
- 客户端严格校验用户ID，只读显示在“我的”和资料弹窗。
- 微信昵称建议、手动昵称、微信头像和本地图片上传继续使用微信官方控件。

验证：账号稳定性、不同账号隔离、旧资料兼容、客户端拒绝伪造、类型、全量测试、云包和微信构建。

结果：已完成并部署study-v2。模拟器确认“我的”资料卡显示公开用户ID，同时保留原头像和昵称。

Review：用户ID生成、旧资料升级与客户端展示均使用同一严格合同；客户端提交资料时不能写入或伪造用户ID。

第一性原理：用户ID用于公开识别账号，应稳定、唯一、不可由客户端控制，也不应暴露微信内部身份，因此仅由服务端从内部账号标识确定性生成。
