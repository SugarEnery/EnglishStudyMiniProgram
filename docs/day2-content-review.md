# 第2天课程审校

使用新版固定种子随机计划的第31—60个目标词，严格按 `wordsForDay(2)` 保持词序；课程日期为2026-10-15。新情境编号为 `oxford-2-301` 至 `oxford-2-306`，不会复用旧情境编号。

| 项目 | 结果 |
|---|---|
| 内容 | 六个原创情境，每个两段、五道英文理解题 |
| 目标词 | 30词，每词恰好出现在两个情境，并恰好对应一道测验 |
| 测验 | 30题，覆盖改写、语境、推断、原因、结果和指代六类 |
| 中文译文 | 逐段对应；段中出现的目标词均用中文括号标出英文 |
| 搭配句式 | 每段两条，说明抽象结构、中文用途和必要语法限制 |
| 查词 | 正文每个词都有中文义与英式IPA；目标词另有分词性常见义 |
| 严格校验 | `validateBatch(day2, wordsForDay(2))` 通过 |

语义复查已逐题对照原文与干扰选项。答案依赖文中明示信息或有依据的改写、推断，未使用同样成立的多个答案。特意区分了 incidence 的发生率、conviction 的坚定信念、court 的球场、grace 的宽厚从容、revolutionary 的根本变革等当前语境义；常见多义保留在 targets.senses，正文查词优先显示本段实际使用的含义。

防止事实夸大：单次洪水不证明长期气候趋势，一次成功测试不证明产品可靠，一次交换活动不宣称解决全球变暖；机器改善劳动负担也不表示消除所有危险。故事均为教学原创情境，不作为真实调查或历史事件陈述。

英文正文已定稿，包括 long-term 与 in chronological order 的最终表述。本文未更改音频、共享验证规则或哈希记录；音频生成及整体验证由主任务统一完成。字典中沿用的非正文词条不参与新情境的目标词计数。
