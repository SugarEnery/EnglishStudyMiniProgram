## 最小验收顺序

1. 游客配置导入，确认首页/学习/计划/我的四个底部菜单；进入学习选择第1/2天，查词和折叠译文，完成情境与测验，确认首页/计划/我的进度同步，重开确认本机恢复。
2. 正式AppID和后端配置就绪后，进入“我的”点击微信登录；没有真实密钥必须显示错误。有效会话重开后应恢复，过期时应提示重新登录。
3. 账号A学习后，账号B登录不得读取A记录；A重新登录应恢复。
4. 所有情境阅读并提交测验后，日期显示数字和对号；切换日期后保留各日进度。
5. 部署现有audio目录及后端，真机试听单词及段落英式MP3，断网或缺文件时显示错误。
6. 发布前运行 `npm run check:audio` 和 `npm run audio:verify`，必须0缺失且全部解码通过。

四菜单补充验收：切菜单保留尚未提交的答案；登录另一个账号不得看到旧答案；“我的”刷新后“学习”恢复最新已提交测验。退出后返回本机第1天，本机记录异常也应保持已退出并显示错误。
