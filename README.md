# Wordscape 微信小程序

默认采用微信云开发：TypeScript云函数、托管文档数据库和云存储。当前study-v2已部署并验证模拟器登录。真实环境ID位于cloudbaserc.json，已核实的音频云存储根位于cloud-config/client.json，正常构建自动读取；普通.env不会自动用于Taro编译。旧HTTP后端保留作显式本地开发。

独立的 Taro + React + TypeScript 工程。网站 `../wordscape` 保持原样。现有第1、2、3天原创随机课程，每日30词、六个情境、逐段译文、搭配句式、全文查义和音标、英文测验、收藏、历史和学习日历。

## 运行

需要 Node.js 22.13 或更新版本，以及微信开发者工具。

```sh
cd miniapp
npm ci
npm run typecheck
npm test
npm run build:cloud
npm run build:daily-cloud
npm run build:weapp
```

微信开发者工具导入本目录，读取 `project.config.json` 的 `dist/`。默认 `touristappid` 是微信游客配置，不是假业务AppID；可本机学习，不能完成微信真实登录。在开发者工具本地设置中关闭合法域名校验后，可连接本机 `http://127.0.0.1:8788`。真机必须使用可访问的HTTPS域名并重新编译 `MINIAPP_API_BASE`。

`npm run dev:weapp` 持续编译；修改云环境或接口编译配置后重启命令。云模式不需要运行npm run server；本地HTTP测试请显式使用MINIAPP_BACKEND=http。

## 四个底部菜单

| 菜单 | 功能 |
|---|---|
| 首页 | 当前学习日、继续学习、完成天数/新词/阅读概况 |
| 学习 | 原有课程选择、日历、情境阅读、查词音频、测验、生词本和历史 |
| 计划 | 登录后设置每日10～80词、查看逐日课程状态并进入学习 |
| 我的 | 微信登录、刷新账号进度、退出登录及个人学习概况 |

使用微信原生tabBar，首次打开进入首页；原`pages/index/index`保留为学习页。四页共用同一会话和记录。切换底部菜单保留未提交答案，换账号会清空原答题界面；已提交结果从该账号的事件恢复。

首页每日一句从云端读取当天发布内容。独立`daily-content`云函数每天凌晨3点使用CloudBase `hy4`生成原创英文和中文译文，再调用腾讯云TTS生成英文MP3；三项全部成功后才写入`daily_sentences`。首页读取失败会明确提示并允许重试，不显示旧内容冒充当天内容。

## 两种记录方式

未登录时默认本机学习，只把事件写到微信本机存储；不冒充微信用户，不自动上传。清除数据会失去本机记录。

未登录首次进入“学习”会看到三天试学开屏。确认后固定从第1天开始，只开放项目现有的三天真实课程，每天30词，包含短文、英式音频和测验；试学不创建正式个人计划，也不受历史本机计划设置影响。开屏在当前设备确认一次，登录后立即改用微信账号计划。

在“计划”或“我的”点击微信登录，调用 `wx.login → POST /api/session → 微信code2Session → 后端自定义会话`。后端通过OpenID隔离每个人的记录，客户端在微信本机存储保存随机会话凭证、到期时间、当前学习日和非敏感会话标识，重新打开验证有效期并读取该账号记录；不存OpenID或AppSecret。凭证过期或服务器拒绝时明确提示重新登录，禁止继续保存，不转为游客模式。登录时先完整读取候选账号课程和记录，再原子替换当前账号；失败保持原账号和记录。用户明确退出时先通知服务端撤销当前凭证，成功后清除账号，再返回本机第1天并加载单独保存的本机记录。真实登录没有密钥时返回503。不会用本机模式掩盖云端失败。

首版本机仅一个独立使用者，不能模拟多微信账号。云端收藏、阅读和测验均按真实身份隔离；服务端重新计算测验分数。提交成功后才显示已保存。每个学习日全部六情境读完且提交测验才在日历打勾，分数不影响完成。

## 内容与共享逻辑

`npm run sync:content` 只从现有网站同步词库、共享类型、分词及严格验证模块，来源SHA256见 `docs/content-provenance.json`。小程序独立维护随机计划与前三天原创课程，不再用网站旧内容覆盖。新增学习日需加入 src/content/catalog.json 与 shared/course-catalog.ts 的静态导入，并完成严格内容及音频检查；前后端和校验脚本共用目录。同步命令保留全部本地课程和随机计划。尚未接入网站每日自动更新任务，未发布的课程不会自动编造。

## 发音

使用 `Taro.createInnerAudioContext` 播放MP3，不依赖浏览器朗读。地址由精确英文文本、`en-GB`、版本号做SHA256生成：`/audio/en-GB/v1/<hash>.mp3`，文本变化会产生新地址。`src/content/audio.json` 是完整清单，包含原文和文件是否存在。

真实iPhone播放前设置不跟随硬件静音开关，因此静音模式下仍可听到学习音频；开发工具和其他平台不调用iOS专用设置，配置失败会直接提示。

当前随机课程与旧版归档合计1128条英式合成MP3已补齐（1056个单词、72个段落）；本次新增561条，旧版567条原样保留，使用macOS Daniel en_GB声线，单词165词/分钟、段落175词/分钟。生成时直接朗读课程原文，保留标点，不替换成旧网站的WAV。文件由开发期FFmpeg编码为44100Hz单声道MP3，并逐个真实解码检查；原文、文件SHA256、原始及解码样本数见 `docs/audio-verification.json`。

测试音频时先运行 `npm run server`，再在微信开发者工具重新编译；本机设置中关闭合法域名校验。真机须将音频与API部署在可访问的HTTPS域名。音频不打包进小程序，服务缺文件返回404，网络或解码失败明确显示。

`npm run audio:verify` 全量解码检查，`npm run check:audio` 检查完整清单及文件指纹；正式构建前自动运行课程与音频检查。`npm run audio:generate` 是macOS开发期生成脚本，固定Daniel英式声线，声线缺失即停止，已有文件会明确拒绝覆盖；生成工具不进入客户端。新增课程可用 npm run audio:generate:missing 仅制作清单中缺少的文件；已存在文件必须通过原报告指纹核对，不能覆盖未知文件。随后重新校验并构建。

## 后端与部署

见 [后端接口说明](server/README.md) 与 [上线清单](docs/wechat-release.md)。后端使用Node内置HTTP服务和串行原子文件存储，不需要改现有数据库。首版仅支持单进程，部署时使用持久磁盘、私有权限和HTTPS反向代理。正式多实例或数据库迁移需另行确认设计。

云开发每日内容上线时，先执行`npm run build:cloud`和`npm run build:daily-cloud`。在微信开发者工具中重新部署`study-v2`，再创建并部署`daily-content`，将其超时设为120秒并上传目录内`config.json`触发器。控制台必须确认触发器对应北京时间凌晨3点；首次手动调用会幂等生成今天和明天。

`daily-content`的语音合成使用仅授权`tts:TextToVoice`的子用户密钥：在云函数环境变量中填写`DAILY_TTS_SECRET_ID`和`DAILY_TTS_SECRET_KEY`。不要覆盖平台的`TENCENTCLOUD_*`临时凭证，不要将密钥写入代码或小程序端。

npm run server 自动加载存在的私有 .env；生产环境也可直接注入变量。`.env.example`仅作配置示例。`WX_APP_SECRET`仅交给后端，禁止出现在编译常量、客户端、日志和版本库。`MINIAPP_API_BASE`仅是公开接口地址。

## 头像与昵称
微信登录成功后直接返回原流程，不强制填写资料。在“我的”可主动选择微信头像、填写昵称并通过微信审核，分别保存到账号；也可暂不修改。重新登录或刷新会同步资料；微信登录本身不会自动提供真实头像昵称。服务端使用sharp校验图片并转换为256×256 PNG，头像只通过带登录凭证的接口读取。

每个微信账号首次登录时由服务端自动生成形如`WS-3DF728D038525830`的公开用户ID。同一账号的ID固定不变，不暴露微信OpenID，客户端只能查看和复制，不能修改；旧账号登录或刷新后自动补齐。昵称仍可使用微信昵称或手动填写，头像仍可选择微信头像或自行上传图片。

每日词数为10～80；单词安排已实现，任意词数自动生成短文与测验尚未接入。

## 开始前设置每日词数
未登录进入“计划”时只显示微信登录入口，不创建本机计划。登录成功后仍停留在计划页，选择每天10～80个词，支持整数输入和滑块；首次默认当天，选择历史日期会在保存前提示将产生的待学习课程。开始前预览总词数、天数和完成日期。保存后按真实Oxford词表生成每天的单词安排，最后一天保留余数，可展开查看；第1天课程已准备时可直接开始学习，未准备时明确显示待生成。修改每日词数或开始日期前会说明新安排重新计算、旧记录保留但不计入新计划进度。
目前支持计划设置和单词日程；每天30词的前3天已有匹配短文、测验和音频，其他词数或后续日期按实际内容显示待制作。原30词课程和学习进度保留在“原有课程与进度”。

学习页面保留原课程、测验、收藏和历史流程；日历可选日期跟随个人计划开始日至今天，未发布课程的日期明确报错，日历仍可切回已有课程。

日历范围和实际课程分别保存：计划已到10天即开放10个可选学习日，不代表10天课程正文已生成。隔天打开学习页更新日历，重新打开保留所选日期；计划变更从第1天开始。
